# BarrierWatcher: focused external comparison, 22 November 2026

First address the confirmed defects in the [independent QA report](QA-2026-11-22.md), especially the P1 missed-follower alarm. The strongest longer-term upgrade investment is then a labelled replay benchmark followed by primary-alarm latency isolation. The current application already has local recognition, region and direction rules, tracked visits, light fallbacks, latest-frame queues, fresh-evidence checks, and clean event evidence. A wholesale NVR replacement is not justified by this research. The recommendations below are proposed experiments, not fixes applied or performance already demonstrated.

## Important implementation boundaries

OpenVINO exposes asynchronous requests, bounded waits and cancellation, but the cited documentation does not promise that cancellation can recover every hung GPU/driver call. `AsyncInferQueue.get_idle_request_id()` waits for an available request; `is_ready()` permits an admission check. Callbacks should publish small, source-tagged results rather than perform disk writes or alarm logic. Multi-request completion order must not be assumed. If isolated tests reproduce an unrecoverable native hang, a watcher-owned child-process boundary is a separate, higher-cost containment design to evaluate; it still does not guarantee driver recovery. These are engineering inferences from the documented APIs and inspected synchronous path, not vendor guarantees. [Inference request](https://docs.openvino.ai/2025/openvino-workflow/running-inference/inference-request.html), [queue API](https://docs.openvino.ai/2025/api/ie_python_api/_autosummary/openvino.AsyncInferQueue.html).

ByteTrack can recover continuity when low-score boxes still exist. It cannot recover a car for which glare produces no usable detection. BoT-SORT's published scope includes motion, appearance and camera-motion compensation; its original pedestrian benchmark results do not establish accuracy or speed on this campus or this PC. Any replacement must preserve route visits, acknowledged identity, source-time confirmation and second-car separation. [ByteTrack authors' description](https://github.com/FoundationVision/ByteTrack), [BoT-SORT authors' description](https://github.com/NirAharon/BoT-SORT).

Frigate's state classifier is a useful experiment design reference: train a fixed region, include an uncertain state and gather varied conditions. Its documentation says training fetches base weights and trained inference is local. No model, licence, GPU purchase or platform migration is recommended here without separate compatibility and deployment review. [State classification](https://docs.frigate.video/configuration/custom_classification/state_classification/).
